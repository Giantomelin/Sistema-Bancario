# 🏦 Sistema Bancário

Sistema bancário desenvolvido em Java com integração ao MySQL utilizando JDBC.

O projeto foi desenvolvido para praticar Programação Orientada a Objetos, SQL,
persistência de dados e operações envolvendo transações bancárias.

## 🚀 Funcionalidades

- Cadastro e consulta de clientes
- Criação e consulta de contas
- Consulta de saldo
- Depósito
- Saque
- Transferência entre contas
- Histórico de transações
- Listagem de clientes

## 🛠️ Tecnologias

- Java 17
- JDBC
- MySQL
- Maven
- Git / GitHub

## 🧠 Conceitos aplicados

- Programação Orientada a Objetos
- Encapsulamento
- Abstração
- Interfaces
- Records
- Collections
- CRUD
- SQL
- DAO (Data Access Object)
- PreparedStatement
- ResultSet
- Tratamento de exceções
- Try-with-resources
- Transações com `commit` e `rollback`
